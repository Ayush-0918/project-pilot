### 🟢 Beginner / Good First Issues

**1. [UI/UX] Add a "Focus Mode" toggle for distraction-free coding**
> **Difficulty:** Beginner
> **Description:** Add a small "Focus Mode" button inside the Project Workspace that hides the sidebar and top navigation, allowing the user to focus entirely on their roadmap tasks and the AI Mentor.

**2. [Feature] Add Audio Feedback (Sound Effects) for Milestone Completions**
> **Difficulty:** Beginner
> **Description:** Gamify the experience further! Add a subtle, satisfying "ding" sound effect (using the HTML5 Audio API) whenever a user clicks the checkbox to complete a project milestone.

**3. [UI] Implement a Pomodoro Timer Widget in the Dashboard**
> **Difficulty:** Beginner
> **Description:** Help developers stay productive by adding a minimal, floating Pomodoro Timer widget (25 min work / 5 min break) in the bottom corner of the active project screen. 

**4. [Feature] Create a "Copy to Notion" Button for Roadmaps**
> **Difficulty:** Beginner
> **Description:** Users often track goals in Notion. Add a button that copies the current project roadmap (formatted perfectly in Markdown with checkboxes) to the clipboard so it pastes cleanly into a Notion page.

**5. [Accessibility] Add "Skip to Content" link for Screen Readers**
> **Difficulty:** Beginner
> **Description:** Improve platform accessibility by adding a hidden "Skip to Main Content" link at the very top of the DOM that becomes visible only on keyboard `Tab` focus, bypassing the sidebar navigation.

**6. [UI] Add animated "Streak" fire icon in the Navbar**
> **Difficulty:** Beginner
> **Description:** Track daily logins or task completions using the Zustand store and display a small "Fire" icon in the top navbar with a streak counter (e.g., "🔥 3 Day Streak").

### 🟡 Intermediate Issues

**7. [Feature] Build a GitHub-style Activity Heatmap**
> **Difficulty:** Intermediate
> **Description:** Instead of just a list for the Activity Feed, use a library like `react-activity-calendar` to visualize the user's project milestone completions over the last 365 days as a green commit graph.

**8. [Feature] Code Snippet "Vault" (Bookmarking System)**
> **Difficulty:** Intermediate
> **Description:** Allow users to click a "Bookmark" icon on valuable code snippets generated by the AI Mentor, saving them to a personal "Code Vault" page in the dashboard for future reference.

**9. [Integration] Discord / Slack Webhook Notifications**
> **Difficulty:** Intermediate
> **Description:** Allow users in the Settings page to paste a Discord or Slack Webhook URL. Whenever they complete a project, the app automatically sends a webhook message celebrating their deployment to their team or friends.

**10. [UX] Implement a Calendar View for Milestones**
> **Difficulty:** Intermediate
> **Description:** Instead of a vertical list, add a "Calendar View" tab using `react-big-calendar` or `@fullcalendar/react` to plot a user's active project milestones visually across the month.

**11. [Feature] "Share AI Conversation" Public Link Generator**
> **Difficulty:** Intermediate
> **Description:** Sometimes the AI Mentor gives a brilliant explanation. Add a "Share Chat" button that creates a read-only, public link to a specific conversation snippet that users can share on Twitter or LinkedIn.

**12. [Feature] Tinder-Style "Interview Flashcards" Mini-Game**
> **Difficulty:** Intermediate
> **Description:** Create a new page where the AI generates technical interview flashcards based on the user's weak points. Use `framer-motion` to allow the user to swipe Right (I knew this) or Left (Need to study) on the cards.

**13. [Architecture] Progressive Web App (PWA) Support**
> **Difficulty:** Intermediate
> **Description:** Configure `next-pwa` and a `manifest.json` so users can install the ProjectPilot AI dashboard directly onto their desktop or mobile phone home screens for app-like access.

### 🔴 Advanced / Complex Issues

**14. [Backend] Integration with WakaTime API**
> **Difficulty:** Advanced
> **Description:** GitHub only tracks commits, not actual hours coded. Integrate the WakaTime API so users can connect their IDE metrics, displaying their actual hours coded vs. hours planned on the project dashboard.

**15. [AI/Backend] Generate SVG "Public Profile Badges" for GitHub READMEs**
> **Difficulty:** Advanced
> **Description:** Create an API endpoint (`/api/badge/:username`) that returns a dynamically generated SVG image showing the user's Career Score, completed projects, and AI readiness. Users can embed this directly in their GitHub Profile READMEs.

**16. [Security/Auth] Implement Custom 2FA Enforcement Flow**
> **Difficulty:** Advanced
> **Description:** Utilize Clerk's multi-factor authentication (MFA) APIs to build a custom UI in the Settings page that allows users to enable and enforce Authenticator App (TOTP) security on their accounts.

**17. [Backend] "Salary Estimator" Machine Learning Integration**
> **Difficulty:** Advanced
> **Description:** Build a feature that calculates an estimated "Market Salary Range" based on the user's completed tech stack milestones, cross-referencing public APIs (like Levels.fyi or local salary data APIs) to motivate them.

**18. [Architecture] Offline Mode (Local First) using IndexedDB**
> **Difficulty:** Advanced
> **Description:** Allow users to view their roadmaps and check off milestones even when they lose internet connection. Sync local changes from IndexedDB to the PostgreSQL backend once the connection is restored using Background Sync.

**19. [AI Feature] "Drop a File" Code Reviewer**
> **Difficulty:** Advanced
> **Description:** Enhance the chat interface to accept `.js` or `.py` file uploads (via UploadThing). The AI Mentor should parse the file contents and provide a dedicated architectural review, highlighting security flaws or performance bottlenecks.

**20. [Architecture] Implement i18n Internationalization for the UI**
> **Difficulty:** Advanced
> **Description:** We have Translate AI for the mentor, but the UI itself is English-only. Setup `next-intl` to support seamless UI switching between English, Spanish, French, and Japanese, storing the user's preference in the database.
